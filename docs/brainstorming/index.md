# Raw Product Brainstorming Notes

*Private product brainstorming & upcoming experimental features.*

## Future Feature Ideas

- **S3 / Gist Config Sync**: Allow synchronizing the `commands.json` file automatically across multiple workstations.
- **Interactive Quick Terminal**: Spawn a tiny overlay terminal when running terminal-based shortcuts, allowing interactive flows.
- **Global Shortcut Daemon**: A background service listening for system-level media or key events to trigger top-bar actions immediately without using mouse clicks.
- **MIDI Controller Support (Completed)**: Physical button mappings, LED feedback, continuous faders, low-latency DJ performance mode, and scene bank switching.

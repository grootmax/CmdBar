# Stream Deck Integration Guide

CmdBar includes full integration support for **Elgato Stream Deck** devices (Stream Deck Mini, Standard, XL, and Plus).

## Features

- **Visual Buttons**: Trigger your favorite CmdBar commands with physical hardware buttons.
- **Feedback LEDs**: Instant visual feedback for command states (Idle, Running, Success, Error).
- **Dynamic Labels**: Display live status, current time, command names, and execution times on key displays.
- **Profile Switching**: Create custom profiles for DevOps, Media, System Utilities, or specific projects, and switch profiles instantly.

## Quick Setup

1. Open CmdBar Companion or Extension Settings.
2. Navigate to **Stream Deck Settings**.
3. Select your device model (`MINI`, `ORIGINAL`, `XL`, `PLUS`).
4. Bind key slots to CmdBar commands or profile switch actions.
